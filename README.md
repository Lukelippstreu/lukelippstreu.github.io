# Luke Lippstreu

Personal academic website, ready for GitHub Pages. Open `index.html` locally to preview it. No installation or build step is required.

## Publish

1. On GitHub, create a public repository named `lukelippstreu.github.io`.
2. Upload the contents of this folder to the repository. `index.html` must be at the repository's top level, alongside `styles.css`, `luke-lippstreu.jpeg` and `luke-lippstreu-cv.pdf`. Upload the files, not a ZIP archive or the surrounding `website` folder.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. When GitHub finishes publishing, visit `https://lukelippstreu.github.io/`.

Use only this website folder for the public repository. It contains the intended webpage, portrait and public CV.

GitHub's instructions: https://docs.github.com/en/pages/quickstart

## Update

- Edit the page text and links in `index.html`.
- Edit the appearance in `styles.css`.
- Replace `luke-lippstreu-cv.pdf` to update the CV without changing its link.
- The original portrait is in `luke-lippstreu.jpeg`; its display crop is set by the `.luke-portrait` styles.

Commit uploaded changes to `main` and GitHub Pages will republish the site.
